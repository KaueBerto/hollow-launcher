O Minecraft já abre com o menu AVERON na primeira execução pelo launcher. Inclui o menu e a tela de carregamento do perfil Dev, com fundo animado otimizado de 1,59 GB para 32 MB.

A preparação inicial baixa as dependências do menu antes de abrir o jogo e reaproveita os arquivos nas próximas aberturas. Configurações existentes são preservadas, e o launcher evita cópias duplicadas dos mods entregues pelo AutoModpack. Nenhum reinício do servidor é necessário.
