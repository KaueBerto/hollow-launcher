# AVERON Launcher 2.8.0

- Usa o perfil configurado pelo responsável pelo servidor como padrão de teclas, sensibilidade, vídeo, áudio, HUD e configurações dos mods.
- Aplica o preset somente em uma instalação nova e apenas para arquivos ausentes; preferências dos jogadores atuais permanecem intactas.
- Exclui contas, sessões, tokens, servidores, mundos, históricos, caches e demais dados pessoais ou transitórios.
- Verifica o ZIP incorporado e cada arquivo com SHA-256 antes de concluir a instalação.
- Preserva o recibo do perfil e todas as preferências durante o reset.
